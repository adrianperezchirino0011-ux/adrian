# Cuba Roleplay 2D Starter (Godot 4)

Proyecto base jugable estilo roleplay 2D para abrir directamente en Godot 4, con presentación **inspirada en UI/isométrico tipo Project Zomboid** (sin zombis y sin usar assets con copyright ajeno).

## Incluye
- Escena urbana con composición en diamante (look isométrico simple).
- Jugador top-down con sprite sobrio estilo supervivencia.
- NPC interactivo (`E`) para loop de trabajo civil.
- HUD tipo survival:
  - panel superior izquierdo (estado, dinero, cívico)
  - barra de vida
  - panel superior derecho (distrito y reloj)
  - quickbar inferior de 8 slots estilo Zomboid.
- Selección de slots con teclas `1-8`.

## Abrir y ejecutar
1. Instala **Godot 4.x**.
2. En Godot: **Import** -> selecciona esta carpeta (`project.godot`).
3. Ejecuta con **F5**.

## Controles
- Mover: `WASD` o flechas
- Interactuar con NPC cercano: `E`
- Equipar slot rápido: `1-8`
